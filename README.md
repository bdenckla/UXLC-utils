# UXLC-utils

UXLC-utils is a redirect host. The 2026-09-03 evacuation moved every published UXLC-utils page to
[MAM-basics](https://bdenckla.github.io/MAM-basics/uxlc/). Each old UXLC-utils URL redirects by a
pure prefix rewrite to the corresponding MAM-basics URL.

UXLC-utils remains on GitHub because old URLs are cited in places Ben cannot reach, including posts
and sent email; there is no enumeration of those citations. UXLC-utils' issue tracker and
pre-evacuation history remain available. UXLC-utils' data and generators are in
[`MAM-basics`](https://github.com/bdenckla/MAM-basics).
